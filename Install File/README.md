# Install Kraken MP3 (Winamp Edition)

This folder holds the **current release** installers for the shipped app.

| File | Use |
|------|-----|
| **Kraken MP3 Setup 1.0.0.exe** | Normal Windows install |
| **Kraken MP3 1.0.0.exe** | Portable (no installer) |

Source and updates: **[kraken-mp3-winamp](https://github.com/krakenunbound/kraken-mp3-winamp)** on GitHub.

The `F:\Kraken_MP3` tree here is a legacy alternate UI; active development and builds use **`F:\Kraken_MP3_Winamp`**.
